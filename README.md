# 家藏本

单机本地家庭台账 App（Flutter MVP，纯离线，无任何网络请求）。

## 功能

- **消耗物资库**：食品 / 护肤品 / 日化用品保质期台账。记录购入日期与外包装到期日期，支持标记开封（开封日期 + 开封后建议天数）；最终失效时间 = min(外包装到期, 开封到期)。列表按 全部 / 临期 / 已过期 筛选。
- **收纳位置管理**：柜子、抽屉、储物箱档案；物件可归属位置、随时挪动；删除位置时强制二选一（物件改为未归位 / 连同删除），无静默级联。
- **全部物件**：普通杂物库存与搜索。
- **首页仪表盘**：进入时前台内存扫描临期（≤30 天）与过期物资，全局搜索与统计。
- **备份与恢复**：全量 JSON 导出 / 导入（导入前校验合法性，事务写入）。
- **标签**：物资与物件可打标签（选已有或新建），MVP 无独立管理页、不支持筛选。

## 技术要点

- Flutter 3 + Material 3；依赖仅 `sqflite`、`path_provider`、`path`。
- 所有 `DateTime` 以 UTC 入库，界面按本地时区展示。
- 数据库写入全部使用事务；临期/过期仅在进入首页时前台计算，无后台任务、无推送。
