# 家藏本

单机本地家庭台账 App（Flutter，纯离线，无任何网络请求）。当前版本 **v1.2.0**。

## 功能

- **消耗物资库**：保质期台账（购入/外包装到期/开封+开封后天数），最终失效时间 = min(外包装到期, 开封到期)；全部/临期/已过期筛选；多选批量开封、批量删除。
- **收纳位置管理**：位置档案与物件归属、挪动；删除位置强制二选一，无静默级联。
- **全部物件**：库存与搜索；多选批量迁移位置、批量删除。
- **首页仪表盘**：进入时前台内存扫描临期（≤30 天）/过期；全局搜索与统计。
- **分类管理**（v1.1）：物资/物件两类分类；有引用禁止删除。
- **标签管理**（v1.1）：重命名、无关联才可删除。
- **录入模板**（v1.2）：物资/物件模板预填表单（如护肤品预设开封后 90 天）。
- **图片附件**（v1.2）：物资/物件/位置可挂多张本机照片，仅存路径不存 BLOB；删除记录时询问是否一并删图。
- **备份与恢复**：全量 JSON 导出/导入（事务+校验；不含图片附件）；CSV/Markdown 清单导出（仅阅读不可导入），MD 支持应用内预览复制。
- **保存筛选方案**（v1.2）：物资列表筛选一键命名保存、加载。

## 技术要点

- Flutter 3 + Material 3；依赖 `sqflite`、`path_provider`、`path`、`image_picker`（本地选图，无网络权限）。
- 所有 `DateTime` 以 UTC 入库，界面按本地时区展示；数据库写入全部事务。
- 数据库版本迁移 v1→v2（分类）→v3（附件/模板/筛选），老数据无损升级。
- 临期/过期仅在进入首页时前台计算；无后台任务、无推送、无 INTERNET 权限。
