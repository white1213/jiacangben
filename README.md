# 家藏本

单机本地家庭台账 App（Flutter，纯离线，无任何网络请求）。当前版本 **v1.4.0**。

## 功能

### 台账核心（v1.0 MVP）
- **消耗物资库**：食品/护肤品/日化保质期台账（购入日期、外包装到期、开封标记 + 开封后天数）；最终失效时间 = min(外包装到期, 开封到期)；全部/临期/已过期筛选
- **收纳位置管理**：柜子/抽屉/储物箱档案；物件归属位置、随时挪动；删除位置强制二选一（物件改为未归位 / 连同删除），无静默级联
- **全部物件**：普通杂物库存与搜索
- **首页仪表盘**：进入时前台内存扫描临期/过期（无后台任务、无推送）；全局搜索（名称+备注）与统计数字
- **备份与恢复**：全量 JSON 导出/导入（事务写入 + 合法性 + 版本标记校验）

### 迭代新增
- **分类管理**（v1.1）：物资/物件两类分类；有引用时禁止删除
- **标签管理**（v1.1）：重命名、仅无关联时可删除
- **多选批量操作**（v1.1）：物资批量开封/删除；物件批量迁移位置/删除
- **清单导出**（v1.1）：CSV / Markdown（仅外部阅读，不可导入回 App）
- **图片附件**（v1.2）：物资/物件/位置可挂多张本机照片（缩略图 + 全屏预览）；仅存路径不存 BLOB；删除记录时询问是否一并删图
- **录入模板**（v1.2）：物资/物件模板预填表单（如护肤品预设开封后 90 天）
- **保存筛选方案**（v1.2，v1.3 支持重命名）：物资列表筛选一键命名保存、加载
- **Markdown 预览**（v1.2）：MD 清单导出后应用内预览、复制
- **设置页**（v1.3）：临期预警天数自定义（默认 30，shared_preferences 持久化）+ 关于/版本号
- **长按菜单**（v1.3）：物资/物件条目长按 编辑 / 多选 / 删除
- **列表筛选弹窗**（v1.3）：分类 + 标签多选（OR 任一命中）+ 状态筛选整合，可与文本搜索叠加；筛选激活时图标高亮；清单导出自动遵循当前筛选
- **领用出库流水**（v1.4）：物资详情页领用出库（扣库存+写流水单事务），流水只读不可篡改；物资新增库存数量字段
- **列表排序**（v1.4）：录入顺序/名称/数量/到期时间，与筛选搜索叠加，保存筛选与导出跟随排序

## 技术要点

- Flutter 3 + Material 3；依赖 `sqflite`、`path_provider`、`path`、`image_picker`、`shared_preferences`
- 所有 `DateTime` 以 UTC 入库，界面按本地时区展示；数据库写操作全部使用事务
- 数据库版本迁移 v1→v2（分类）→v3（附件/模板/筛选），打开时幂等 schema 自愈校验，任意历史版本数据无损升级
- 表单校验：开封日期不得晚于外包装到期日期
- JSON 备份仅含文字记录，不含图片附件（界面醒目提醒手动备份照片）
- 临期/过期仅在进入首页时前台计算；无后台任务、无系统通知、无 INTERNET 权限
